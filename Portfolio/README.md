# Pratik — portfolio

A responsive portfolio made with plain HTML, CSS, and JavaScript. The hero is a lightweight CSS-built orbital illustration with a subtle pointer tilt, so it works without a build step, network request, or WebGL dependency. The custom `assets/pratik-logo.svg` mark is used in the header, footer, and favicon; the original reference image is kept in `assets/pratik-logo-reference.png`.

## Preview

Open `index.html` directly in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Make it yours before publishing

- Edit the introduction, about copy, services, and concept descriptions in `index.html`.
- The three project cards are **illustrative concepts**, not claims of shipped client work. Replace them with your real work, or keep them labeled as concepts.
- Replace `pratik@example.com` in the contact link with your real email address.
- Use `assets/pratik-logo.svg` anywhere you need the logo; it has a transparent background and scales cleanly for web, social, and print use.
- Adjust the color tokens and layout in `styles.css` (`:root` at the top). All the illustrations are in that file too.

Project cards can be opened to read more. The CSS hero responds subtly to the pointer on fine-pointer devices and respects reduced-motion preferences; the site remains usable without JavaScript.
